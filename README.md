# ICOS weekly update · 1 Oct 2026

Interactive weekly update for the ICOS modular legged robot. Open `index.html` (or the GitHub Pages link) in a browser; it has two tabs:

1. **Whole robot** (`robot.html`): body v3 with its electronics and four V79 legs, 13 assembly steps, exploded view, size checks.
2. **Latch assembly** (`assembly.html`): the quick-release dock latch in 9 steps, on the V79 root block and the V71 receiver, including the zip tie.

Everything is static HTML. The 3D views use three.js r128 (`vendor/three.r128.min.js`, MIT licence). `leg.html` and `media/` are from the 24 Sep update and are no longer linked.

To update: replace the files on github.com (*Add file → Upload files*), then *Commit changes*. Pages rebuilds in about a minute.
